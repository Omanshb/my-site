# To-Do

## 1) First blog: 10 pieces of advice
- [ ] Lead with one clear point: decide the single takeaway before writing.
- [ ] Open with a specific moment or story, not a generic intro.
- [ ] Write in your natural voice; do not force a "blog tone."
- [ ] Prefer concrete details over abstract claims.
- [ ] Keep paragraphs short so it reads well on mobile.
- [ ] Use simple structure: hook -> context -> core idea -> examples -> close.
- [ ] Cut any sentence that does not move the argument forward.
- [ ] Add one strong visual (photo, diagram, or screenshot) if it helps comprehension.
- [ ] End with a memorable closing line or one actionable question.
- [ ] Publish, then iterate: ship version one and refine based on feedback.

## 2) Notes page: formatting + content pass
- [ ] Tighten spacing/typography hierarchy across `writings`, `readings`, and `thoughts`.
- [ ] Ensure card/list rhythm is consistent (title, metadata, takeaway alignment).
- [ ] Improve section labels for `videos`, `papers`, `blogs`, and `books`.
- [ ] Add a fuller curated set of entries for all four categories.
- [ ] Include outbound links where possible and verify they open correctly.
- [ ] Check responsive behavior on mobile/tablet/desktop.

## 3) Media page: finalize image gallery
- [ ] Define final gallery structure (sections, order, and cover image behavior).
- [ ] Add the full image set to the page with consistent aspect ratios.
- [ ] Write concise captions/alt text for accessibility and context.
- [ ] Tune crop/position so important subjects are not clipped.
- [ ] Optimize image loading performance (sizes, quality, and lazy-loading strategy).
- [ ] Verify final look and interactions across breakpoints.
